About BitDark.net

BitDark is an independent cybersecurity operations workspace, digital privacy hub, and defensive educational initiative. We develop browser-native utilities designed to safeguard privacy, audit application security, and prevent data leakage without relying on remote servers. Every tool is engineered to execute entirely inside your local device memory with zero server-side telemetry.

🔒 The Zero-Network-Egress Architecture

Traditional web-based utility sites require users to upload confidential documents, cryptographic keys, authorization tokens, and personal photos to cloud servers for remote processing. This design introduces severe confidentiality risks, unintended third-party data retention, and compliance liabilities.

BitDark solves this fundamental security risk through a Provable Zero-Network-Egress model. By taking full advantage of modern browser APIs, all computations run locally on your client machine's CPU and memory:

W3C Web Cryptography API

Key pair generation (RSA/ECDSA), hashing (SHA-256, SHA-512), and encryption (AES-GCM, PBKDF2) run directly on browser-native cryptographic hardware primitives without revealing keys over the wire.

Sandboxed WebAssembly (WASM)

Complex forensic parsers, database engines (SQLite), and memory-intensive hashing algorithms (Argon2) execute inside an isolated, sandboxed WebAssembly runtime on your local device.

Dedicated Web Workers

CPU-intensive forensic sweeps, multi-gigabyte file checksums, and dictionary entropy checks operate across background threads, ensuring your main UI thread remains fluid and responsive.

HTML5 Canvas & Binary Streams

Image metadata purging, EXIF GPS stripping, and video/audio container parsing process byte-level data directly in memory, discarding sensitive tracking headers before files ever touch storage.

⚙️ The Defensive Toolkit Ecosystem

BitDark organizes its utilities into seven tactical domains engineered for developers, system administrators, security auditors, and privacy-conscious users:

1. AI Defense, Provenance & Agent Security
Client-Side Heuristics

Utilities engineered to safeguard workflows against emerging artificial intelligence threat vectors, synthetic media manipulation, and prompt injection vulnerabilities.

Key Tools: C2PA Provenance Manifest Reader (inspects Coalition for Content Provenance and Authenticity claims), Prompt Injection Rule Scanner (evaluates system instructions for jailbreaks and role escapes), llms.txt & AI Crawler Policy Maker (generates directives for GPTBot, ClaudeBot, and CCBot), Zero-Width Prompt Injection Scanner (detects invisible adversarial text smuggling), Homoglyph Phishing Detector, Deepfake Image Artifact Inspector, and Context Window Token Calculator.
2. Privacy, OSINT & Metadata Sanitization
Data Leakage Prevention

Defensive utilities built to audit, sanitize, and strip sensitive tracking signatures before sharing files, text, or links across untrusted networks.

Key Tools: EXIF & Metadata Stripper (purges GPS coordinates, camera models, and timestamps from images in-memory), PII & Secret Redactor (scrubs API tokens, email addresses, and IPs from text blocks), PDF Metadata Redactor, URL Tracking Strip Tool (removes UTM, gclid, and fbclid tokens), Canvas Steganography Tool (extracts payload data from pixel Least Significant Bits), WebRTC Local IP Leak Checker, and Browser Storage Manager & Nuker.
3. Cryptography & Key Management
W3C WebCrypto Native

Provably air-gapped cryptographic utilities that allow verification, signing, and encryption without sending private keys across the internet.

Key Tools: AES-256-GCM Encryptor, Multi-Hash Checksum Generator (calculates MD5, SHA-1, SHA-256, and SHA-512 simultaneously), RSA Key Pair Generator (2048/4096-bit key creation), Bcrypt & Argon2 Hasher, BIP-39 Mnemonic Generator, TOTP 2FA Token Generator (RFC 6238), Shamir's Secret Sharing Tool, and Diceware Passphrase Lab.
4. AppSec, Tokens & Web Standards
Auditor & Developer Tools

Security validation utilities for modern web development, assisting engineering teams in configuring safe HTTP headers, authentication tokens, and browser policies.

Key Tools: JWT Offline Debugger & Verifier (inspects claims and validates signatures without transmitting secrets), CSP Rule Builder & Evaluator, Subresource Integrity (SRI) Builder, OAuth2 PKCE Challenge Generator, X.509 Certificate & CSR Decoder, Password Entropy & Strength Lab, Contextual XSS Sanitizer, and SQL Injection Parameterizer.
5. Network, DNS & Infrastructure Diagnostics
Sysadmin Utilities

Calculators and diagnostic parsers that help network operators, IT administrators, and security teams troubleshoot configurations without external network lookups.

Key Tools: IPv4/IPv6 Subnet & CIDR Calculator, CIDR Overlap & Collision Resolver, Raw Email MIME Header Tracer (parses SPF, DKIM, and relay hops), DMARC Record Builder & Linter, Nginx Hardening Linter, Docker Compose Security Linter, and RFC 5424 Syslog Parser.
6. Data Encoders & Byte Transformation
Radix & Payload Utilities

In-browser data format converters for inspecting complex payloads, resolving character encoding mismatches, and debugging raw byte structures safely.

Key Tools: Base64 / Base32 / Base85 Suite, Binary File Hex Dumper (xxd), Percent & Double-URL Decoder, Protobuf Raw Wire Decoder, ReDoS Catastrophic Backtracking Tester, Gzip & Brotli Decompressor, and Base58 & Base62 Codec.
7. Binary Inspection & Digital Forensics
Sandboxed Local Analysis

Analytical tools for examining unverified binaries, parsing packet captures, and inspecting structured data files in a fully isolated browser environment.

Key Tools: File Magic Byte / MIME Identifier, Binary Strings Extractor (extracts ASCII and UTF-8 strings from binaries), ZIP Path Traversal (Zip Slip) Scanner, SQLite Database Viewer (queries tables locally via WASM), PCAP Packet Capture Visualizer, SVG Image Sanitizer & XSS Scanner, and Tarball Archive Explorer.
