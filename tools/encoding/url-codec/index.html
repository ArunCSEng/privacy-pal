Understanding Percent-Encoding (RFC 3986)

Uniform Resource Identifiers (URIs) reserve specific characters (such as :, /, ?, #, [, ], and @) as syntax delimiters. When data characters conflict with these reserved delimiters or contain non-ASCII code points, they are encoded into hexadecimal byte sequences prefixed by the percent sign (%).

Which Mode Should You Choose?

  • encodeURIComponent: Best for query string parameter keys and values. Escapes all characters except A-Z a-z 0-9 - _ . ! ~ * ' ( ).
  • encodeURI: Best for complete URLs where protocol (https://), slashes, and hash anchors should remain intact while encoding invalid characters.
  • application/x-www-form-urlencoded: Standard HTML form submission format where space characters are converted to + rather than %20.
