What is Base58 Encoding?

Base58 is a binary-to-text encoding scheme developed by Satoshi Nakamoto for the Bitcoin cryptocurrency network. Unlike Base64, Base58 intentionally removes characters that appear identical or ambiguous in standard fonts, preventing human transcription errors and ambiguity in printed materials.

The six omitted characters are:

  • 0 (Number zero) and O (Uppercase letter O)
  • I (Uppercase letter I) and l (Lowercase letter L)
  • + (Plus) and / (Slash), which can break line breaks and URL paths

How Base58Check Validation Works

Base58Check adds a 4-byte double SHA-256 checksum to prevent typos when transcribing Bitcoin and cryptocurrency addresses:

  • Payload Packaging: A version prefix byte is prepended to the payload data.
  • Double Hashing: The combined data is hashed twice with SHA-256: SHA256(SHA256(payload)).
  • Checksum Append: The first 4 bytes of the double hash are appended to the payload.
  • Conversion: The combined buffer is encoded using the Base58 algorithm. Any transcription mistake alters the decoded checksum, allowing software to reject invalid addresses before transmitting assets.
