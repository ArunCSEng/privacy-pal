What ROT13 Is

ROT13 is a Caesar cipher that rotates each letter 13 places through the alphabet: A becomes N, B becomes O, and so on. Because the alphabet has 26 letters and 13 is exactly half, the same operation both scrambles and unscrambles text — encode and decode are identical. It's the classic way to lightly hide text: spoiler tags, puzzle answers, joke punchlines, mild obfuscation in forums. This tool applies ROT13 and its relatives, in your browser.

ROT13 Is Not Encryption

The most important thing to be clear about: ROT13 provides no security whatsoever. It's a fixed substitution with no key — anyone can reverse it instantly, and this very page does. Use it to stop someone reading text by accident (a spoiler they haven't chosen to reveal), never to protect anything that matters. If data needs to stay private, it needs real encryption, not a letter rotation.

The Variants

ModeRotates
ROT13Letters A–Z and a–z by 13
ROT5Digits 0–9 by 5
ROT18ROT13 on letters and ROT5 on digits together
ROT47All printable ASCII (33–126) by 47 — letters, digits and punctuation

ROT47 obscures more than ROT13 because it also moves numbers and symbols, which is useful when plain letters-only rotation would leave too much readable. All of these share the self-inverse trick: ROT13 (13+13=26), ROT5 (5+5=10) and ROT47 (47+47=94) each return to the start when applied twice, so one button does both directions.

A Worked Example You Can Reproduce

ROT13:  Hello World  →  Uryyb Jbeyq
ROT47:  Hello World! →  w6==@ (@C=5P

Feed Uryyb Jbeyq back through ROT13 and you get Hello World again — proof of the self-inverse property. Note that ROT13 only touches letters: spaces, digits and punctuation pass through unchanged, which is why the tool shows both a rotated count and an untouched count for what you enter.

Frequently Asked Questions

How do I decode ROT13?
Apply ROT13 again. Because rotating by 13 twice moves a letter a full 26 places back to itself, the same operation encodes and decodes — there's no separate decode step. The same is true of ROT5 and ROT47.
Is ROT13 secure?
No. ROT13 has no key and is trivially reversible by anyone, so it offers zero security. It's meant to hide text from accidental reading — spoilers, puzzle answers — not to protect sensitive data. For real protection, use encryption.
What's the difference between ROT13 and ROT47?
ROT13 rotates only letters, leaving digits and punctuation untouched. ROT47 rotates all printable ASCII — letters, digits and symbols — so it scrambles more of the text. Both are self-inverse and equally non-secure; ROT47 just hides a wider range of characters.
Why are some characters left unchanged?
In ROT13, only alphabetic characters are rotated; spaces, numbers and punctuation pass through as-is. The tool reports how many characters it rotated versus left untouched, so you can see exactly what was affected. Use ROT47 if you also want digits and symbols rotated.
Is my text sent anywhere?
No. The transformation runs entirely in your browser, so nothing you type is uploaded. That said, ROT13 isn't private in any meaningful sense — anyone can decode it — so the local processing is about convenience, not confidentiality.
