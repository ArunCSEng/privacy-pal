Understanding HTML Entity Encoding in AppSec

HTML entity encoding replaces reserved markup characters with safe character references so the browser's HTML lexical parser interprets them as literal text data rather than executable DOM nodes or script tags.

Character Description Named Entity Decimal Hexadecimal
& Ampersand (Entity initiator) &amp; &#38; &#x26;
< Less-than (Opens HTML tag) &lt; &#60; &#x3C;
> Greater-than (Closes HTML tag) &gt; &#62; &#x3E;
" Double Quote (Attribute breakout) &quot; &#34; &#x22;
' Single Quote / Apostrophe &apos; &#39; &#x27;
/ Forward Slash (Closes tags) &sol; &#47; &#x2F;
` Backtick (Template literal breakout) &grave; &#96; &#x60;

Encoding Formats Explained

  • Named Entities: Human-readable aliases defined by the HTML5 specification (such as &lt; and &copy;). Ideal for standard web templates and documentation.
  • Decimal Numeric References: Represent Unicode code points in base-10 format (&#60;). Widely compatible across legacy XML and HTML parsers.
  • Hexadecimal Numeric References: Represent Unicode code points in base-16 format (&#x3C;). Frequently inspected during Web Application Firewall (WAF) rule evaluation and DOM parser normalization analysis.
