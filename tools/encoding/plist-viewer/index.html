Apple Property List Formats Explained

Property lists are serialization formats utilized extensively across Apple platforms (macOS, iOS, watchOS, tvOS) to store user preferences, application bundles, configuration states, and security entitlements:

  • Binary Plist (bplist00): A compact binary format introduced in Mac OS X 10.2. It packs primitives (integers, booleans, dates, floats, and binary blobs) with an offset table and trailer referencing the root object graph.
  • XML Plist (Version 1.0): A structured text format validated by Apple's DTD schema (Apple//DTD PLIST 1.0//EN), featuring explicit typed tags such as <dict>, <key>, <array>, <string>, and <data>.
  • OpenStep / NeXTSTEP Plist: The historical ASCII format preceding XML, using curly braces for dictionaries and semicolons as terminators.
