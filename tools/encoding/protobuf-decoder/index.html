How Schema-less Protobuf Decoding Operates

Protocol Buffers serialize structured data into compact binary streams. Unlike JSON or XML, field names and schema structures are omitted over the wire. Each tag is transmitted as a variable-length integer (Varint) packing two critical values: (field_number << 3) | wire_type.

  • Wire Type 0 (Varint): Represents int32, int64, uint32, uint64, sint32, sint64, bool, or enum using 7-bit LEB128 chunking.
  • Wire Type 1 (64-bit): Fixed-length 8 bytes, representing fixed64, sfixed64, or IEEE 754 double.
  • Wire Type 2 (Length-delimited): Prefixed by a length Varint, representing UTF-8 strings, byte arrays, embedded messages, or packed repeated fields.
  • Wire Type 5 (32-bit): Fixed-length 4 bytes, representing fixed32, sfixed32, or IEEE 754 float.

Zero Network Egress Security

BitDark's Protobuf Decoder operates entirely within local browser sandboxing using native Web APIs (Uint8Array, DataView, TextDecoder, and crypto.subtle). Binary bytes are never uploaded to remote servers or third-party analytical endpoints.
