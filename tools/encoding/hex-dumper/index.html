What a Hex Dump Shows

A hex dump lays out the raw bytes of a file or text in three columns: the offset (the hex address of each row), the bytes in hexadecimal, and an ASCII sidebar where printable characters appear and everything else shows as a dot. It's the fundamental way to see what's actually inside a file, below any format or encoding. This tool produces that view and adds file-type detection, an entropy reading, a SHA-256 hash, hex search and C-array export — all in your browser.

Magic Bytes: a File's Real Type

The first few bytes of most formats are a fixed signature — a "magic number" — that identifies the real type no matter what the extension says. A PNG always starts 89 50 4E 47, a JPEG FF D8 FF, a PDF 25 50 44 46 (%PDF), a GIF 47 49 46 38. The tool reads these and names the format, which is how you catch a file that's been renamed or mislabeled: a .jpg that begins with %PDF is a PDF, whatever it's called. The bytes don't lie.

Entropy: a Randomness Reading

Entropy measures how unpredictable the bytes are, from 0 to 8 bits per byte (Shannon entropy). It's a useful hint about what you're looking at:

EntropyUsually means
Low (~1–4)Text, source code, structured data — lots of repetition
Medium (~5–7)Mixed binary, some formats
High (~7.5–8)Compressed or encrypted data — near-random bytes

It's a clue, not a verdict. High entropy can't tell encrypted data from compressed data — both look random — so use it to notice something interesting (why is this config file's region near-random?), not to prove what it is. The reading reflects the bytes currently in view, so paging through a large file shows how entropy varies across it.

Frequently Asked Questions

How do I read the three columns?
The left column is the offset — the hex address of the first byte in that row. The middle is the bytes in hexadecimal. The right is the ASCII view, where printable characters are shown and non-printable bytes appear as dots. Together they let you locate and read any byte in the data.
What are magic bytes, and why do they matter?
They're a fixed signature at the start of a file that identifies its real format — 89 50 4E 47 for PNG, %PDF for PDF, and so on. Because they're in the content, not the filename, they reveal a file's true type even if its extension has been changed or removed.
What does the entropy number tell me?
It's a 0–8 measure of randomness. Low values (around 1–4) suggest text or structured data; high values (7.5–8) suggest compressed or encrypted bytes. It's a hint, not proof — it can't distinguish encryption from compression, since both look random.
Does the hash cover the whole file?
Yes — the SHA-256 is computed over the entire file (up to a size limit to keep the browser responsive), so it matches sha256sum and can be used to verify or identify the file. The entropy reading, by contrast, reflects the slice currently shown.
Is my file uploaded to inspect it?
No. The file is read and analysed entirely in your browser, and nothing is sent to a server. That makes it safe to inspect private documents, keys or any sensitive binary.
