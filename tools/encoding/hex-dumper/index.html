How Canonical Hex Dumping & Magic Byte Detection Works

A canonical hexadecimal dump displays the exact byte sequence of a file or memory buffer alongside its printable ASCII representation. Every byte (8 bits) is represented as a two-digit base-16 value ranging from 00 to FF.

  • Magic Bytes (File Signatures): Operating systems and forensic tools identify file formats by reading the first few bytes of a file rather than trusting file extensions. For example, Portable Executables (PE/EXE) begin with 4D 5A (MZ), ELF binaries start with 7F 45 4C 46 (.ELF), and PNG images begin with 89 50 4E 47 0D 0A 1A 0A.
  • Shannon Entropy Analysis: Measures randomness within a byte window on a scale from 0.0 to 8.0 bits per byte. Plaintext ASCII typically scores between 3.5 and 5.0, whereas compressed archives, packed malware, or encrypted payloads approach 7.9+.

Zero Network Egress & Sliced Memory Architecture

Uploading proprietary firmware, memory dumps, or sensitive documents to cloud-based hex viewers exposes confidential data. BitDark's Hex Dumper utilizes the native Blob.slice() and FileReader Web APIs to read 4 KB windows on demand directly from disk—meaning you can inspect multi-gigabyte files smoothly on desktop or mobile with zero network egress.
