How Bitwise Operators Operate in Silicon and Software

Bitwise operators manipulate integers at the level of individual binary digits (bits). Rather than treating values as cohesive quantities, bitwise instructions apply primitive Boolean gates concurrently across each bit position:

  • AND (&): Yields 1 only if both corresponding bits are 1. Commonly used for bitmasking and checking flag status.
  • OR (|): Yields 1 if either corresponding bit is 1. Commonly used to set or pack flags without disturbing adjacent bits.
  • XOR (^): Yields 1 if the operand bits differ. Essential for parity calculation, cryptographic hashing, and toggling specific bits.
  • NOT (~): Unary operator that inverts each bit. In two's complement systems, ~x equals -(x + 1).
  • Logical vs Arithmetic Shifts: Left shift (<<) appends zero bits to the right. Signed right shift (>>) preserves the most significant sign bit, while unsigned zero-fill right shift (>>>) pushes zeros regardless of sign.

Two's Complement Representation

Modern microprocessors represent signed integers using two's complement notation. In an $N$-bit system, the most significant bit (MSB) carries a negative weight of $-2^{N-1}$, while all lower bits carry positive binary weights. This ensures standard addition circuits handle both positive and negative values without requiring dedicated subtraction silicon.
