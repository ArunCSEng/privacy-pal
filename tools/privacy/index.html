Understanding Client-Side Privacy Auditing & Zero Egress

When users upload files or sensitive documents to conventional web-based sanitizers, their data is typically transmitted across public networks and cached in remote cloud databases. This creates severe exposure risks, including unintentional regulatory non-compliance and exposure to third-party data breaches.

Zero Network Egress

Every tool in this directory processes files, credentials, and image headers locally in volatile memory using HTML5 Canvas, Web Streams, and DataView APIs. Disconnecting your device from the internet will not interrupt tool availability.

Dynamic YAML Discovery

When new privacy utilities are published under /tools/privacy/, this hub synchronizes via tools.yml automatically, registering and rendering the new tools without manual code edits to the hub.

Ad Script Isolation

Third-party advertising scripts (including Google AdSense) execute strictly within sandboxed layout boundaries and have zero technical access to in-memory files, stripped EXIF tags, or redacted PII strings.

Frequently Asked Questions About Privacy Tools

How does the EXIF & Metadata Stripper remove GPS tags without uploading photos?

The tool reads image binary buffers into local browser memory via the HTML5 FileReader and Canvas APIs. It draws the raw pixel array onto an offscreen canvas and re-encodes the image as a clean raster without writing back the APP1, EXIF, or XMP metadata segments, ensuring zero bytes ever leave your machine.

Does the PII & Secret Redactor retain copies of redacted API keys or personal data?

No. The PII Redactor processes text purely in-memory using compiled JavaScript regular expressions. It scrubs AWS keys, Bearer tokens, emails, IPv4 addresses, and phone numbers in local RAM, discarding the original buffer immediately after sanitization.

How does the WebRTC Local IP Leak Checker detect internal network exposure?

The tool initializes a temporary RTCPeerConnection in your browser to request local Interactive Connectivity Establishment (ICE) candidates. It parses the resulting SDP offers locally to inspect whether your private LAN IP (e.g., 192.168.x.x or 10.x.x.x) is leaked past VPN or proxy tunnels.

What parameters are stripped by the URL Tracking Cleaner?

The URL Tracking Cleaner strips marketing and analytics query parameters such as utm_source, utm_medium, utm_campaign, gclid, fbclid, msclkid, mc_eid, and cross-site click IDs using native browser URL parsing, leaving only the clean destination address.

How does the Browser Fingerprint Audit calculate entropy signatures?

It probes local browser rendering characteristics—such as WebGL renderer strings, Canvas 2D geometric fill differences, AudioContext oscillator frequency shifts, and installed font fallbacks. It computes a local cryptographic hash of these entropy vectors without saving or transmitting the signature to any third party.

Can these privacy tools be operated completely offline without an internet connection?

Yes. Once this page finishes loading, all underlying JavaScript engines, Canvas transformers, and binary parsers remain cached in browser memory. You can disconnect your network connection or enable Airplane Mode, and every tool in this suite will continue to function normally.
