⚠️ Redaction Limitations & Document Sanitization Boundaries

Stripping document metadata dictionaries does not redact visible page content or buried vector layers. This utility neutralizes the catalog /Info dictionary, incremental revision chains, and /Metadata XML streams (Adobe XMP). It does not scan for or purge OCR text, hidden layers, embedded file attachments, font table metadata, or visual text covered by superficial black rectangle shapes. Always execute visual redactions via vector rasterization before public distribution.

How PDF Metadata Leakage Occurs

PDF documents are structured object trees (ISO 32000-1). When word processors and desktop publishing engines export a file, they serialize system names, registered user identities, local file directory paths, and software build hashes into standardized fields:

  • Classic /Info Object: Contains key-value mappings such as /Author, /Creator, /Producer, /CreationDate, and /ModDate.
  • XMP Metadata Stream: An XML packet embedded directly inside the document catalog under /Metadata containing Dublin Core schemas, Photoshop histories, and printer UUIDs.
  • Incremental Update Appends: When PDFs are modified without full flattening, editors append new revision bodies at the file tail, keeping obsolete author names fully recoverable in previous cross-reference tables (xref).
