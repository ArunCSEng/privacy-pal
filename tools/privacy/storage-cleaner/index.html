Understanding Modern Browser Persistence Layers

While HTTP cookies remain the classic tracking mechanism, modern web applications utilize a layered suite of persistence APIs that operate silently inside the browser runtime:

  • Web Storage (LocalStorage & SessionStorage): Synchronous key-value stores holding string payloads up to 5MB–10MB per origin. LocalStorage persists indefinitely across reboots, while SessionStorage expires when the browsing context closes.
  • IndexedDB: A transactional, object-oriented NoSQL database system supporting structured cloning, binary Blobs, typed arrays, and large storage quotas. Often used by offline-first web applications and persistent tracking scripts.
  • Cache API: Request/Response pair caching used by Service Workers to enable progressive web apps. Untracked cache keys can store identifiable network payloads across restarts.
  • Storage Quota API (navigator.storage): Provides origins with programmatic insight into disk usage and persistence guarantees (e.g., persistent vs. best-effort eviction policies).
