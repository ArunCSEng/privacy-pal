⚠️ Operational Boundaries & Network Isolation Disclaimer

Cryptographic validation does not indicate service availability or reachability. This utility confirms address syntax, Base32 RFC 4648 compliance, public key extraction, and structural version markers purely via local client-side evaluation. It does not resolve addresses over the Tor network, query Hidden Service Directories (HSDirs), or perform directory lookup descriptors. Under no circumstances does this validator transmit evaluated addresses across the network. Understanding Onion Service Address Formats

Tor hidden services rely on self-authenticating domain names derived directly from public keys. Depending on the specification generation, onion domains follow distinct structures:

  • Version 3 (V3 - Standard): 56-character Base32 strings consisting of a 32-byte Ed25519 public key, a 2-byte SHA3-256 checksum (computed over .onion checksum || pubkey || version), and a 1-byte version identifier (\x03).
  • Version 2 (V2 - Deprecated): 16-character Base32 strings representing an 80-bit truncated SHA-1 hash of an RSA-1024 public key. Deprecated since Tor version 0.4.6.x due to SHA-1 vulnerability risks.

Zero Network Egress Security Guarantee

Pasting onion addresses into public network services or search engines can compromise service privacy through search engine indexation or DNS leaks.
