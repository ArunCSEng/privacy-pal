⚠️ Privacy Scope & Re-encoding Disclaimer

Local canvas scrubbing strips application container headers, but does not alter visual pixel content. While this tool purges binary EXIF, GPS, XMP, and MakerNote chunks by recreating the raster image from raw pixels, it will not redact physical identifiers embedded in the scene itself (e.g., license plates, street signs, barcodes, house numbers, or reflections). Always inspect image contents visually before sharing. Re-encoding lossy images (JPEG/WebP) may introduce minor visual compression artifacts.

How Client-Side Metadata Sanitization Operates

Digital cameras and smartphones embed extensive metadata payloads into file headers at capture time:

  • JPEG APP1 (0xFFE1) Segments: Contain Exif IFD structures storing precise GPS latitude/longitude coordinates, altitude, capture timestamps, camera make/model, firmware, and unique hardware serials.
  • Adobe XMP & IPTC Blocks: Store edit history, creator names, software version stamps, and copyright information.
  • PNG / WebP Ancillary Chunks: Embed auxiliary text chunks (tEXt, zTXt, eXIf) that disclose host environments and rendering pipelines.

The HTML5 Canvas Sanitization Pipeline

Rather than attempting to parse and delete specific header tags one-by-one—which risks missing proprietary manufacturer offsets or MakerNotes—BitDark executes a pure raster reconstruct. The image bytes are decoded strictly into an in-memory 2D Canvas Context. The browser then draws the raw pixel array into an isolated raster buffer and generates a completely clean JPEG/PNG binary container. The resulting file contains zero non-pixel segments.
