⚠️ Limitations & Disclaimer

Removing metadata does not make an image anonymous. The pixels are unchanged, and they routinely identify a place or a person on their own — a street sign, a recognisable room, a reflection, a document on the desk. Sensor and lens characteristics can also link photographs taken with the same camera, and that survives both metadata removal and re-encoding. Two practical notes: the export is produced by decoding and re-encoding the image, so a JPEG source is recompressed and the file is not bit-identical to the original — keep your original if quality matters; and this works on the copy you export, never on the file sitting on your disk. Everything runs in your browser and the image is never uploaded. Results are provided as-is; BitDark.net is not liable for decisions made from them.

What This Tool Does

Drop in a photo and the tool reads the metadata the camera or phone embedded — and on a phone photo with location services on, that usually includes the coordinates where it was taken, to within a few metres. Seeing that list is half the value, because most people underestimate how much is in there.

The second half is the export. The image is decoded to raw pixels on a canvas and encoded again from those pixels. Metadata is not edited out tag by tag; it simply has nowhere to live in the new file.

How to Use the Tool

  1. Load an image by dropping it onto the page or selecting it. JPEG from a phone or camera is the interesting case — that is where GPS and device details live.
  2. Read the metadata panel first. Look for GPS coordinates, the capture timestamp, camera make, model and serial number, and software fields. This is what every copy of that file has been carrying.
  3. Check the coordinates if they are present by pasting them into a map. It is the quickest way to understand why photos taken at home are worth stripping.
  4. Click Download Scrubbed Image. The export is a JPEG written from the canvas pixels, named with a scrubbed_ prefix so you do not confuse it with the original.
  5. Verify by re-loading the output into this tool. The metadata panel should be empty, which is a check you can perform yourself rather than taking the claim on trust.
  6. Click Clear Analysis to remove the image, its metadata and the generated download from the page.

What Is Actually Embedded

EXIF was designed for photographers, and its fields are useful: exposure, aperture, focal length, orientation, timestamp. The privacy problem arrived with GPS. A phone with location services enabled writes latitude and longitude into every photo, and a set of photos from one person therefore carries a map of where they have been, with timestamps.

Alongside EXIF, files often carry XMP blocks written by editing software, IPTC fields used in publishing, and an embedded thumbnail — which has historically caused trouble, because a thumbnail generated before a crop can preserve the part of the image that was cropped out. Device serial numbers appear in some cameras' metadata and link every photo from that body together.

Why Re-Encoding Is the Reliable Method

A metadata editor removes the fields it knows about. Formats carry fields it may not, in vendor-specific blocks and extensions, so a tag-by-tag approach can leave something behind.

Decoding to a canvas sidesteps the problem. What arrives on the canvas is a grid of pixel values; the metadata was interpreted during decode and then discarded. Encoding from that canvas produces a file whose only content is those pixels plus whatever minimal header the format requires. Nothing can survive that it does not survive by being pixels. The cost is recompression, which for a JPEG source means a second lossy pass — worth it for sharing, worth avoiding for a master copy.

Where the Original Still Matters

The file on your disk is untouched. Everything here happens to a copy held in memory, so stripping metadata for a photo you are about to send does nothing for the twenty copies of it already in a shared album, in a backup, or in a message you sent last year. Metadata travels with every copy that was made before you stripped it.

The durable fix is upstream: turn off location tagging in the camera app for photos you expect to share, and strip as a habit on the way out rather than as a rescue after the fact. If a photo has already been published with coordinates in it, replacing the published copy is the only thing that helps, and even then you should assume the original was collected.

A Worked Example You Can Reproduce

Take a photo on a phone with location services enabled and load it here. Note the GPS coordinates and paste them into a mapping service — they will point at where you were standing. Note the capture time and the camera model as well. Download the cleaned copy, then load that copy back into the tool: the metadata panel comes back empty. Compare file sizes too; the difference is partly the discarded metadata and the embedded thumbnail, partly re-encoding. Finally, look at the picture itself and ask what it still shows. That question is the one metadata stripping cannot answer for you.

Frequently Asked Questions

Does re-encoding reduce image quality?
Yes, if the source is a JPEG. The image is decoded to pixels and encoded again, and that second JPEG pass is lossy, so the output is not bit-identical to the original even where it looks the same. For sharing on the web this is usually irrelevant. For archival or print masters, keep the original and share the stripped copy.
Which metadata does this actually remove?
All of it, by construction. The canvas holds pixels and nothing else, so EXIF, GPS coordinates, camera make and model, serial numbers, timestamps, XMP blocks, IPTC fields and any thumbnail are simply absent from the re-encoded file. That is a stronger guarantee than editing individual tags, because there is no tag list to miss anything.
Does stripping metadata make a photo untraceable?
No. The pixels are untouched and they carry plenty: recognisable interiors, street signs, reflections, a view from a window, documents on a desk. Beyond content, sensor noise patterns and lens characteristics can link images from the same camera, and that survives metadata removal and re-encoding. Metadata is the easy leak, not the only one.
Will social platforms not strip metadata anyway?
Most do on upload, but you should not rely on it. Behaviour varies by platform and by upload path, some preserve more than others, and direct sharing — email, messaging apps sending as a file, cloud links, a web form — generally preserves everything. Strip before you send and the question stops mattering.
Is my photo uploaded anywhere?
No. The file is read into memory in your browser, drawn to a canvas and exported locally. Nothing is transmitted, and the image is gone from the page when you reload it or click Clear Analysis.
