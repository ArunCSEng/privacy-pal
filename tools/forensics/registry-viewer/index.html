Windows Registry Hive Architecture

The Windows Registry is a hierarchical configuration database stored on disk as binary files termed "hives". Unlike standard plaintext configuration formats, binary hives adhere to the Windows Registry format:

  • REGF Header: The first 4,096 bytes (0x1000) contain the primary hive header, commencing with the ASCII signature regf, sequence numbers, last modification timestamps (64-bit Windows FILETIME), and an offset pointer to the root cell.
  • HBIN Allocations: Following the header, data is segmented into 4 KB chunks prefaced by hbin. These blocks house key cells (nk), value cells (vk), subkey lists (lf, lh, ri), and data cells.
  • Standard Hive Paths:
    • SYSTEM, SOFTWARE, SAM, SECURITY → %SystemRoot%\System32\config\
    • NTUSER.DAT → %SystemDrive%\Users\<Username>\NTUSER.DAT
    • Amcache.hve → %SystemRoot%\appcompat\Programs\Amcache.hve
