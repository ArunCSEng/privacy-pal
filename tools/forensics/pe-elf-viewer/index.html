Binary Format Anatomy

Modern executables rely on strictly defined file envelopes that tell the operating system kernel loader how to map code and memory segments into virtual space.

  • Portable Executable (PE): Utilized across Microsoft Windows environments. Begins with an MS-DOS 2.0 stub identified by the magic bytes MZ (0x4D 0x5A), followed by a 4-byte PE signature pointer at offset 0x3C. It encompasses COFF headers, Optional Headers specifying target subsystems, and an array of section descriptors (e.g., .text for machine code, .data for global variables, and .rsrc for icons and manifests).
  • Executable and Linkable Format (ELF): The native standard binary format for Linux, Android, BSD, and system utilities. Begins with the 4-byte identification sequence 0x7F 'E' 'L' 'F', encoding target bitness (32-bit vs 64-bit), endianness, target instruction set architecture (x86_64, AArch64, ARM, RISC-V), and program/section table offsets.
