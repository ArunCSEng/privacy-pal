    In-Browser WebAssembly Architecture

    This utility initializes an isolated SQLite virtual machine compiled directly to WebAssembly (sql.js). When a file is loaded, it is read into an ArrayBuffer and instantiated completely offline within memory:

    • Zero Network Egress: Database records, sensitive credential caches, or browser history stores are never uploaded across network ports.
    • Read-Only Safety: Queries run against the in-memory virtual image, ensuring original local files remain untouched and unmodified on disk.
    • Forensics & Inspection: Allows instant query diagnostics for mobile app databases, browser storage files (e.g., Chrome/Firefox History or Cookies), and system caches without external native software installation.
