Why SVGs Are Vectors for Cross-Site Scripting (XSS)

Scalable Vector Graphics (SVG) are XML-based documents rather than raster image buffers. Because the W3C SVG specification fully integrates DOM Level 2 scripting, style sheets, and hyperlinking, an SVG can execute JavaScript when rendered directly or embedded improperly.

  • Inline Executables: Tags such as <script>, <foreignObject>, <iframe>, and <use> references to external resources can execute arbitrary scripts.
  • Event Handlers: Inline attributes including onload, onerror, onclick, and onmouseover trigger script execution upon document load or interaction.
  • Hyperlink Hijacking: <a href="javascript:..."> payloads bypass standard image perimeter filters.
  • Entity Expansion (XXE): Custom <!DOCTYPE> declarations and internal entity definitions can consume browser resources (Billion Laughs attack) or attempt SSRF/local file reads.

Sanitization Protocol

BitDark's sanitizer parses input via the native browser DOMParser in an isolated XML context. It recursively walks every node, strips external entity references, removes forbidden tags via localName checking, purges event listener attributes, cleans href attributes containing executable pseudo-protocols, and reconstructs a safe SVG tree.
