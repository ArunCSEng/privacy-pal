Radix Encoding Specifications

Binary-to-text encodings translate raw 8-bit byte arrays into printable ASCII characters so payloads survive transmission across text-only protocols such as SMTP, HTTP headers, JSON documents, and blockchain ledgers.

  • Base64 & Base64URL (RFC 4648): Maps 6 bits per character across a 64-character alphabet. Base64URL substitutes + and / with - and _ and strips = padding so tokens can be placed safely in URLs and JSON Web Tokens (JWTs).
  • Base58 (Bitcoin / IPFS): Designed by Satoshi Nakamoto to eliminate visually ambiguous characters (0, O, I, l) and non-alphanumeric symbols (+, /), making wallet addresses and cryptographic keys safe to copy via double-click.
  • Base32 (RFC 4648): Uses a case-insensitive 32-character set (A–Z and 2–7), commonly used in Time-based One-Time Password (TOTP) 2FA secret seeds and DNS-compatible identifiers.
  • Hexadecimal (Base16) & Binary: Directly represents each byte as two 4-bit nibbles (00–ff) or eight individual bits (00000000–11111111).
