How Content Security Policy Protects Web Applications

Content Security Policy (CSP) is a declarative HTTP response header mechanism defined by W3C that restricts the origins and resources (scripts, images, stylesheets, frame embeddings) a web browser is permitted to execute:

  • XSS Mitigation: Restricting script-src prevents untrusted remote script injections and neutralizes reflected/stored Cross-Site Scripting vectors when unsafe evaluation primitives are prohibited.
  • Framing & Clickjacking Protection: The frame-ancestors directive supersedes legacy X-Frame-Options headers to define which parent origins can embed the page inside <iframe> elements.
  • Base Tag Injection Defense: Setting base-uri 'none' or 'self' neutralizes HTML injection attacks that alter the document's relative URL resolution root via <base href="..."> tags.
  • Object & Plugin Blocking: Enforcing object-src 'none' blocks Flash, Silverlight, and Java applet execution surfaces completely.
