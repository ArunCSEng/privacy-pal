About JSON Web Keys (JWK) & Sets (JWKS)

A JSON Web Key (JWK) is an open cryptographic data structure standardized under RFC 7517 that represents a cryptographic key using standard JSON naming conventions. A JSON Web Key Set (JWKS) is a container object featuring an array of JWKs, typically distributed by OAuth 2.0 and OpenID Connect (OIDC) identity providers (such as Auth0, Okta, Keycloak, or Google) at well-known discovery endpoints (/.well-known/jwks.json).

Key Conversion & Web Crypto Compatibility

This utility natively interfaces with the browser's window.crypto.subtle engine and internal ASN.1 DER parsers to deserialize SubjectPublicKeyInfo (SPKI) X.509 structures and map them directly to standard JWK parameters without any server-side dependencies:

  • RSA Keys: Supports modulus (n) and exponent (e) mapping for standard key sizes (1024, 2048, 3072, 4096 bits) with PKCS#1 and SPKI compatibility.
  • Elliptic Curves: Supports NIST curves P-256, P-384, and P-521 with validated coordinate points (x, y).
  • RFC 7638 Thumbprints: Standard SHA-256 JWK thumbprints are computed over required key components in lexicographical order to calculate deterministic kid identifiers.
