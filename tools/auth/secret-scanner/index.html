How Client-Side Secret Detection Works

Hardcoded secrets represent a primary initial access vector in cloud and infrastructure security breaches. This utility identifies credential exposures through dual-vector static analysis:

  • Deterministic Signatures: Regex rules identify structured formats with specific prefixes, including AWS Access Keys (AKIA...), GitHub Personal Access Tokens (ghp_..., github_pat_...), Slack Tokens (xox[baprs]-...), Google API Keys (AIza...), Private Keys (-----BEGIN...PRIVATE KEY-----), Stripe Keys, and Database Connection Strings (postgres://..., mongodb://...).
  • Shannon Entropy Evaluation: The scanner extracts isolated token assignments and computes statistical Shannon entropy:
    $$H(X) = -\sum_{i=1}^n P(x_i) \log_2 P(x_i)$$ Strings with high entropy ($H \ge 4.45$ bits/char for alphanumeric, or $H \ge 3.4$ bits/char for hexadecimal) indicate randomized API secrets, symmetric encryption keys, or HMAC salts.
