How to Read a Cipher Suite

A TLS 1.2 cipher suite name lists the algorithms a connection will use. Reading TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256 left to right:

PartRole
ECDHEKey exchange. The "E" means ephemeral, which gives forward secrecy
RSAAuthentication: the certificate type that proves the server's identity
AES_128_GCMBulk encryption. GCM is an AEAD mode (encryption plus built-in integrity)
SHA256The hash used for the handshake (in AEAD suites, not a separate MAC)

TLS 1.3 simplified this. Its five suites, such as TLS_AES_128_GCM_SHA256, name only the bulk cipher and hash, because TLS 1.3 always uses ephemeral key exchange and AEAD. This tool decodes both, and maps between IANA names, OpenSSL names and the two-byte wire codes.

How the Tool Grades a Suite

GradeMeaningExamples
A+AEAD cipher with forward secrecyAll TLS 1.3 suites; ECDHE/DHE with GCM or ChaCha20-Poly1305
BForward secrecy, but older CBC mode with an HMACECDHE-RSA-AES128-SHA, ECDHE-RSA-AES256-SHA256
FNo forward secrecy, or a broken primitiveStatic-RSA suites, 3DES, RC4, NULL (no encryption)

Two things drive a low grade. No forward secrecy: a static-RSA suite like TLS_RSA_WITH_AES_128_GCM_SHA256 is graded F even though AES-GCM itself is strong, because a future compromise of the server key would expose past recorded traffic. Broken primitives: RC4 and 3DES are retired, and NULL means no encryption at all.

How to Use the Analyzer

  1. Paste a cipher suite by IANA name, OpenSSL name, or two-byte code, or click a preset.
  2. Read the breakdown: key exchange, authentication, encryption, integrity, forward secrecy and protocol version.
  3. Use it to translate names between the IANA form (in RFCs and packet captures) and the OpenSSL form (in server configs).
  4. Prefer A+ suites and disable F ones in your server configuration.

Choosing Suites for a Server

  • Enable TLS 1.3 and, for TLS 1.2, keep only ECDHE suites with GCM or ChaCha20-Poly1305.
  • Disable static RSA, CBC, 3DES, RC4 and NULL. Also disable SSL 3.0, TLS 1.0 and TLS 1.1.
  • Follow a maintained baseline rather than hand-picking: the Mozilla SSL Configuration Generator produces current configs for common servers.
  • Test the live server with a scanner such as SSL Labs or testssl.sh; this tool decodes a suite but doesn't connect to your server or see what it actually negotiates.

This reference covers a curated set of common suites. Names it doesn't recognise are parsed heuristically from the text, which can be approximate or wrong, so trust the decode only for suites it matches exactly, and verify your server with a dedicated scanner.

Frequently Asked Questions

What is forward secrecy and why does it matter?
Forward secrecy means each session uses a temporary key, so recording encrypted traffic today and stealing the server's private key later won't decrypt it. It needs an ephemeral key exchange (ECDHE or DHE). Suites using static RSA lack it, which is why they're graded F here.
Why is a static-RSA AES-GCM suite graded F when AES-GCM is strong?
The cipher is fine; the key exchange isn't. Static RSA provides no forward secrecy, so a later key compromise exposes past sessions. The grade reflects the whole suite, not just the bulk cipher.
What's the difference between AEAD and CBC suites?
AEAD modes (GCM, ChaCha20-Poly1305, CCM) combine encryption and integrity in one step and avoid the padding and timing problems that have affected CBC-with-HMAC suites. Prefer AEAD; CBC suites are graded as merely tolerated.
How do I enter a cipher by its hex code?
Enter the two wire bytes as a pair, for example 0x00,0x9E or 0x13,0x01. That's the form the tool matches reliably. You can also use the full IANA or OpenSSL name.
Does this tool check my server's TLS configuration?
No. It decodes and grades a cipher suite you type, entirely in your browser, and makes no connection to any server. To see what your server actually offers and negotiates, run SSL Labs or testssl.sh against it.
