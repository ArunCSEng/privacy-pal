RFC 1035 Domain Name System Wire Framing

A standard DNS message transmitted over UDP or TCP port 53 consists of a fixed 12-byte header followed by variable-length Question, Answer, Authority, and Additional sections:

  • Fixed 12-Byte Header: Contains the 16-bit Transaction ID (TXID), 16-bit operational flags (QR bit, Opcode, AA, TC, RD, RA, Z, RCODE), and four 16-bit counters detailing the entries per section (QDCOUNT, ANCOUNT, NSCOUNT, ARCOUNT).
  • QNAME Length-Octet Encoding: FQDNs do not use standard ASCII delimiters like dots. Instead, domains are serialized as a sequence of labels where each label is preceded by an 8-bit length octet (e.g., example.com becomes 0x07 example 0x03 com 0x00), terminated by a zero byte (0x00).
  • QTYPE & QCLASS: Every question concludes with a 16-bit type specifier (e.g., 0x0001 for Type A, 0x001c for Type AAAA) and a 16-bit class specifier (virtually always 0x0001 for Internet/IN).
  • DNS Message Compression: Resource records often replace redundant domain labels with two-byte compression pointers starting with bit flags 11xxxxxx (0xC0), pointing to an earlier byte offset in the packet.
