BGP AS-Path Attribute Mechanics

The AS_PATH attribute is a mandatory well-known BGP path attribute that records every Autonomous System an update traverses:

  • Directionality & Origin: The origin network is located at the far right of the sequence. As the route traverses eBGP sessions, each intermediate boundary router prepends its own ASN to the front (left) of the attribute list.
  • Loop Prevention: When a BGP router receives an update containing its own AS number anywhere in the AS_PATH, it rejects the advertisement to prevent forwarding loops.
  • AS-Path Prepending: Engineers artificially repeat their own AS number multiple times to make the route appear longer, dissuading adjacent networks from choosing it via the BGP best-path selection algorithm.
  • Tier Hierarchy: Tier-1 transit backbones (e.g., Lumen AS3356, Arelion AS1299, Cogent AS174, NTT AS2914) peer settlement-free and form the core transit fabric of the global Internet.
