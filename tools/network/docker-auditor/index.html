Common Container Security Anti-Patterns

Containers provide application isolation using Linux kernel namespaces, cgroups, and seccomp filters. Overriding these controls exposes the underlying host kernel to total takeover:

  • Privileged Mode (privileged: true): Disables almost all container security controls, passes all host devices to the container, and allows trivial breakout to root host control.
  • Docker Socket Mount (/var/run/docker.sock): Mounting the host Docker daemon socket into a container grants root-equivalent privileges on the host system via the Docker API.
  • Host Namespaces (network_mode: host, pid: host, ipc: host): Bypasses network isolation, permits packet interception, and allows inspection or signaling of host processes.
  • Missing Capabilities Dropping (cap_drop: - ALL): Containers inherit unnecessary Linux capabilities (such as CAP_NET_RAW or CAP_CHOWN) by default unless explicitly dropped.
  • Mutable Root Filesystem: Lacking read_only: true permits attackers or compromised processes to persist binaries, alter configuration, and unpack malicious payloads.
