IP Address Representations & Alternate Notations

IP addresses are fundamentally fixed-length binary integers (32 bits for IPv4, 128 bits for IPv6). Because systems display and parse addresses in various notations, understanding each representation is vital for network programming, firewall configuration, and vulnerability auditing:

  • Dotted-Decimal (IPv4 standard): Four 8-bit octets separated by dots (e.g., 192.168.1.1).
  • Decimal Integer (Dword): The direct 32-bit or 128-bit unsigned integer value. Many operating systems, URL parsers, and command-line utilities natively resolve single decimal values to valid IPs (e.g., http://3232235777 routes to 192.168.1.1).
  • Hexadecimal & Octal: Web browsers and HTTP libraries historically permit octal (prefixed with 0) and hexadecimal (prefixed with 0x) notation. Attackers occasionally employ these alternate formats to bypass URL filter blacklists and Web Application Firewalls (WAFs).
  • RFC 5952 IPv6 Compression: Dictates modern IPv6 canonical representation: all hexadecimal characters must be lowercase, leading zeros inside hextets must be suppressed, and the longest contiguous run of two or more zero hextets must be replaced with a single ::.
  • Reverse DNS (PTR): The hierarchical domain name assigned to an IP under in-addr.arpa (for IPv4) or ip6.arpa (for IPv6) used for reverse lookup validation.
