MAC Address Architecture & IEEE Bit Flags

A standard MAC address (EUI-48) consists of 48 bits (6 octets) displayed as hexadecimal numbers. The first 3 octets define the Organizationally Unique Identifier (OUI), and the final 3 octets represent the Network Interface Controller (NIC) specific identifier:

  • Individual / Group (I/G) Bit: Least significant bit of the first octet. When set to 0, the frame is Unicast (directed to a single host). When set to 1, the frame is Multicast or Broadcast (e.g., FF:FF:FF:FF:FF:FF).
  • Universal / Local (U/L) Bit: Second least significant bit of the first octet. When set to 0, the address is Universally Administered (assigned by the manufacturer via IEEE OUI). When set to 1, the address is Locally Administered (randomized MAC address used by iOS, Android, and Windows for Wi-Fi privacy or configured manually by an administrator).
  • EUI-64 Expansion: Used extensively in IPv6 Stateless Address Autoconfiguration (SLAAC). A 48-bit MAC is transformed into a 64-bit identifier by inserting FF:FE in the middle and inverting the U/L bit.
