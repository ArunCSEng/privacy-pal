Syslog Architecture: RFC 3164 vs RFC 5424

The Syslog protocol serves as a standard mechanism for sending event notification messages over IP networks:

  • Priority (PRI): Contained within angle brackets (e.g. <165>) representing an 8-bit number. The Facility code is calculated as floor(PRI / 8) and the Severity code is PRI mod 8.
  • RFC 3164 (BSD Syslog): The legacy format consists of a PRI, a local timestamp without timezone offset (e.g. Oct 11 22:14:15), a hostname, and a message body typically prefixed with the process name and PID.
  • RFC 5424 (IETF Syslog): The modern standard introduces structured headers: PRI VERSION TIMESTAMP HOSTNAME APP-NAME PROCID MSGID STRUCTURED-DATA MSG. Timestamps must follow ISO 8601 / RFC 3339 format with precise UTC offsets, and structured data blocks are enclosed in square brackets ([id key="val"]).
  • Facilities & Severities: Facilities range from 0 (kernel) to 23 (local7). Severities range from 0 (Emergency) to 7 (Debug).
