CIDR Interval Mathematics & Collision Types

Subnet overlap detection evaluates whether the numeric range defined by two CIDR blocks intersects along any bit boundaries:

  • Exact Duplicate: Both CIDR blocks define identical start and end numeric boundaries (e.g., 10.0.0.0/24 vs 10.0.0.0/24). This introduces routing asymmetry or route-table rejection.
  • Containment (Parent / Subnet): One CIDR block's range is entirely enveloped within another wider prefix (e.g., 10.0.1.0/24 inside 10.0.0.0/16). In longest-prefix-match (LPM) routing engines, traffic prefers the more specific route, potentially shadowing parent security policies.
  • Partial Cross-Boundary Intersections: Standard CIDR subnets cleanly nest or remain disjoint; irregular wildcards or malformed netmasks that fail prefix alignment can result in irregular segment collisions.
