What This Tool Does

CIDR (Classless Inter-Domain Routing) writes an IP block as an address and a prefix length, like 192.168.1.0/24. The prefix says how many leading bits are the fixed network part; the rest address the hosts inside the block. Give this tool an IPv4 or IPv6 address and a prefix and it works out the block's boundaries — network and broadcast address, subnet and wildcard mask, and the usable host range and count — instantly, in your browser. Nothing you type is sent anywhere; it is pure arithmetic done locally.

Network, Broadcast and Mask

A prefix splits the 32 bits of an IPv4 address into network bits and host bits. Setting all the host bits to zero gives the network address (the block's identifier); setting them all to one gives the broadcast address (its last address). The subnet mask is simply the network bits shown as an address — /24 is 255.255.255.0 — and the wildcard mask is its inverse, 0.0.0.255, the form access-control lists use. The tool derives all of these with the same bitwise operations a router uses.

Usable Hosts, and the /31 and /32 Cases

In an ordinary IPv4 subnet the network and broadcast addresses are reserved, so the usable hosts are the total addresses minus two — a /24 has 256 addresses and 254 usable. Two prefixes are special: a /32 is a single address (one usable, no broadcast), and a /31 has just two addresses, which RFC 3021 allows to be used as both ends of a point-to-point link. The tool follows RFC 3021 and reports two usable hosts for a /31 rather than zero, which is the behaviour real routers expect.

A Worked Example You Can Reproduce

Enter 192.168.1.10/26 and the tool shows:

Subnet mask255.255.255.192
Wildcard mask0.0.0.63
Usable host range192.168.1.1 – 192.168.1.62

A /26 fixes 26 bits, leaving 6 host bits, so the block holds 26 = 64 addresses and 62 usable. The host address .10 falls inside the 192.168.1.0 block, so the network is .0 regardless of which address in the block you entered. You can check the figures against ipcalc 192.168.1.10/26 on Linux.

IPv6

IPv6 uses the same prefix idea with 128-bit addresses, so the tool computes those with big-integer arithmetic. There is no broadcast address in IPv6, so for a prefix it reports the network prefix and the first and last address of the range rather than a broadcast and a minus-two host count. Prefixes are usually aligned to nibble (4-bit) boundaries — /32, /48, /56, /64 — with /64 the standard size for a single LAN.

Frequently Asked Questions

What does the number after the slash in a CIDR block mean?
It is the prefix length: how many leading bits of the address are fixed as the network part. In 192.168.1.0/24 the first 24 bits are the network and the remaining 8 are for hosts. A larger number means a smaller block — /24 holds 256 addresses, /25 holds 128, and so on.
Why are the usable hosts two fewer than the total addresses?
In a normal IPv4 subnet the first address is the network identifier and the last is the broadcast address, and neither is assigned to a host, so usable hosts are the total minus two. A /24 has 256 addresses and 254 usable. The exceptions are /31 and /32, explained below.
How are /31 and /32 handled?
A /32 is a single host address, so it has one usable address and no broadcast. A /31 has only two addresses; RFC 3021 lets both be used on a point-to-point link, with no separate network or broadcast address, so the tool reports two usable hosts for a /31 rather than zero.
What is the wildcard mask for?
The wildcard mask is the bitwise inverse of the subnet mask — for /24 the mask is 255.255.255.0 and the wildcard is 0.0.0.255. It is the form used in access-control lists on Cisco-style devices, where a 1 bit means "this bit can be anything", so the tool shows it alongside the netmask.
How is IPv6 different here?
IPv6 uses the same prefix idea but with 128-bit addresses and no broadcast address, so the tool reports the network prefix and the first and last address of the range rather than a broadcast and a host count minus two. Prefixes are usually written on nibble (4-bit) boundaries, such as /32, /48 and /64.
