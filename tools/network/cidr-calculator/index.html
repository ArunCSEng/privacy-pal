Classless Inter-Domain Routing (CIDR) Overview

CIDR represents IP addresses using a base network address appended by a prefix length specifying the quantity of significant bits constituting the network routing identity.

  • IPv4 Routing Allocations: Based on 32-bit addresses divided into network and host bits. A /24 subnet reserves 24 bits for the network segment and 8 bits for host addresses, yielding 256 addresses (254 usable hosts minus the network identifier and the broadcast boundary).
  • IPv6 Global Unicast Prefixes: Utilizes a 128-bit address space. Typical allocations assign a /48 or /56 prefix to end-sites, leaving individual subnets at a standard /64 bit boundary to maintain stateless address autoconfiguration (SLAAC) compatibility.
