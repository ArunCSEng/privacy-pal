Understanding MTU, MSS, and Encapsulation Penalties

The Maximum Transmission Unit (MTU) establishes the largest physical frame payload a network link can transport without IP fragmentation. The Maximum Segment Size (MSS) specifies the largest payload a TCP client or server can accept in a single unfragmented packet:

  • Standard Ethernet Formula: On standard Ethernet (1500 MTU) over IPv4 (20-byte header) and standard TCP (20-byte header), the optimal TCP MSS is $1500 - 20 - 20 = 1460\text{ bytes}$.
  • IPv6 Header Penalty: IPv6 incorporates a fixed 40-byte base header (double IPv4). On a 1500-byte MTU, IPv6 TCP MSS is $1500 - 40 - 20 = 1440\text{ bytes}$.
  • The TCP Clamping Imperative: If ICMP Type 3 Code 4 ("Fragmentation Needed and DF set") packets are dropped by intermediate firewalls, PMTUD blackholing occurs. Routers resolve this at network edges by rewriting the TCP SYN packet MSS option via MSS clamping.
  • Tunnel Overhead Accumulation: Modern cloud and VPN architectures stack multiple encapsulations (e.g., Ethernet + VXLAN + IPv4 + WireGuard + Inner IPv6). Each layer deducts available payload space, necessitating precise client MTU adjustments.
