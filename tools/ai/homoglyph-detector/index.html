What a Homograph Attack Is

Many letters in other alphabets look identical to Latin letters. Cyrillic а (U+0430) and Latin a (U+0061) are drawn the same way in most fonts, but they're different characters, so аpple.com with a Cyrillic first letter is a completely different domain from apple.com. Attackers register lookalikes like this for phishing links.

Domain names can't contain non-ASCII characters in DNS, so internationalized domain names (IDNs) are converted to an ASCII form that starts with xn--, using the Punycode algorithm (RFC 3492). The Cyrillic lookalike above is actually registered as xn--pple-43d.com. In 2017, researcher Xudong Zheng showed that xn--80ak6aa92e.com, spelled entirely in Cyrillic, appeared as "apple.com" in Chrome and Firefox. Browsers have since tightened their rules, but no rule catches every case.

What This Tool Checks

  • Per-character breakdown. Every character is listed with its Unicode codepoint and script (Latin, Cyrillic, Greek and so on).
  • Known lookalikes. 40 Cyrillic, Greek and dotless-i characters that resemble Latin letters are flagged as "Spoof Risk" with the letter they imitate.
  • Other non-Latin characters are flagged as "Non-Latin Character" and counted.
  • Punycode. Each label containing non-ASCII characters is converted to its xn-- form, the domain that's actually registered.
  • Warning banner. It shows a warning if there's any flagged character, any mix of Latin with Cyrillic, Greek or extended Latin, or any xn-- label.

How to Use the Homoglyph Detector

  1. Paste a domain or full URL from a suspicious email or message. The tool strips the scheme and path and keeps the hostname.
  2. Read the character table. Any row that isn't plain Latin, digits or punctuation is worth a look. "Spoof Risk (Matches 'a')" tells you which letter is being imitated.
  3. Compare the Punycode. If it starts with xn-- and you expected a plain English domain, you're looking at a different site.
  4. Copy the Punycode to look up the real registration (WHOIS, or your email security tools) or to add it to a blocklist.

Enter domains in lowercase. Browsers lowercase a domain before encoding it, but this tool encodes exactly what you type, so Аpple.com with a capital Cyrillic А gives xn--pple-kzd.com here, while a browser would go to xn--pple-43d.com.

What It Doesn't Catch

  • ASCII lookalikes and typos. rn for m (rnicrosoft.com), 1 for l, 0 for o, and misspellings use only plain ASCII, so they show as clean.
  • Lookalikes outside the list. Unicode's official confusables data (UTS #39) lists thousands of lookalike pairs; this tool's list covers the 40 most common. Other non-Latin characters are still flagged, but without a matching letter.
  • Hidden characters inside xn-- input. Pasting xn--pple-43d.com triggers the warning, but the tool doesn't decode it, so the table only shows ASCII letters. Paste the Unicode form if you have it.
  • Lookalike subdomains. apple.com.example.net is plain ASCII, but the real domain is example.net. Always read a hostname from the right.

Frequently Asked Questions

What does xn-- at the start of a domain mean?
It marks an internationalized domain name encoded with Punycode. The browser shows the Unicode version when it judges it safe, and the xn-- version when it doesn't. If a link you expected to be plain English shows xn--, it contains non-ASCII characters.
Why is a real domain like münchen.de flagged?
The tool flags every character outside basic Latin letters, digits and punctuation, including accented Latin letters such as ü. That makes it cautious but noisy. Use the character table to tell an accented letter in a real word from a Cyrillic or Greek lookalike.
Why does my Punycode differ from what the browser shows?
Browsers lowercase domain names before encoding them, and this tool encodes exactly what you type. Enter the domain in lowercase to get the same xn-- form a browser would use.
Can it detect typosquatting like rnicrosoft.com?
No. Those domains use only ordinary ASCII letters, so there's nothing for a character check to flag. Compare the spelling carefully, or use a typosquatting scanner that generates and checks likely misspellings.
Is the domain I enter sent anywhere?
No. Character analysis and Punycode encoding run in JavaScript in your browser, and the tool makes no DNS lookups or network requests with what you type.
