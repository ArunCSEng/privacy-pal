How to Use the Agent User-Agent Inspector

  1. Paste a User-Agent string from your access logs (the quoted field at the end of a typical Nginx or Apache log line). Results update as you type.
  2. Or click a preset to load a sample string for GPTBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot, HeadlessChrome or desktop Chrome. The presets are examples; real crawlers change their version numbers over time.
  3. Click "Use My Browser" to inspect your own browser's navigator.userAgent. Clearing the field does the same.
  4. Copy the result. "Copy Disallow Directive" copies the robots.txt rule shown in the output box. "Copy JSON Analysis" copies the classification as JSON for a ticket or log note.

Worked Example 1: Blocking Training While Staying in AI Search

OpenAI documents GPTBot's current User-Agent as: 

Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko); compatible; GPTBot/1.4; +https://openai.com/gptbot

Paste it into the inspector and it reports OpenAI, AI Ingestion & Training, and the directive User-agent: GPTBot / Disallow: /. To keep appearing in ChatGPT, Claude and Perplexity search while opting out of training, block the training crawlers and allow the search crawlers: 

# Opt out of AI model training
User-agent: GPTBot
User-agent: ClaudeBot
User-agent: CCBot
User-agent: Google-Extended
User-agent: Applebot-Extended
Disallow: /

# Stay visible in AI search results
User-agent: OAI-SearchBot
User-agent: Claude-SearchBot
User-agent: PerplexityBot
Allow: /

Sitemap: https://example.com/sitemap.xml

This doesn't change your Google Search rankings, because Googlebot isn't named. User-requested agents such as ChatGPT-User and Perplexity-User may not follow these rules at all, because a person asked for the page.

Worked Example 2: A Request Claiming to Be Googlebot

Your logs show this string: 

Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)

The inspector reports it as a Standard Interactive Browser, because Googlebot isn't one of its signatures. That's a reminder that the header alone proves nothing: anyone can send this string with curl -A. To check it, look up the connecting IP address. Google's documentation uses this example: 

$ host 66.249.66.1
1.66.249.66.in-addr.arpa domain name pointer crawl-66-249-66-1.googlebot.com.

$ host crawl-66-249-66-1.googlebot.com
crawl-66-249-66-1.googlebot.com has address 66.249.66.1

The request is genuine only if the reverse lookup ends in googlebot.com, google.com or googleusercontent.com, and the forward lookup returns the same IP. Google also publishes its crawler IP ranges as JSON files for automated checks.

Verify the IP Address, Not the String

A User-Agent is a free-text header, so this tool tells you what a client claims to be. Before you allow or block traffic, check the source:

  • Reverse DNS plus a forward check works for Google (googlebot.com, google.com, googleusercontent.com), Apple (applebot.apple.com) and Common Crawl (crawl.commoncrawl.org).
  • Published IP lists are the method for OpenAI, Anthropic and Perplexity. Their documentation doesn't describe reverse DNS verification, so match the source IP against their JSON files instead.
  • Headless browsers and scripts don't read robots.txt. Headless Chrome includes HeadlessChrome in its User-Agent by default, but automation frameworks can replace it with a normal Chrome string. Rate limits and behaviour, not the header, are what catch those.

If you block by User-Agent at your web server, match on the token, and remember that it only stops clients that identify themselves honestly: 

# Nginx: return 403 to self-identified AI training crawlers
map $http_user_agent $ai_training_bot {
    default 0;
    ~*(GPTBot|ClaudeBot|CCBot|Bytespider|Meta-ExternalAgent) 1;
}

server {
    listen 443 ssl;
    http2 on;
    server_name example.com;
    # ssl_certificate and ssl_certificate_key as usual

    if ($ai_training_bot) {
        return 403;
    }
}

Frequently Asked Questions

What's the difference between GPTBot, OAI-SearchBot and ChatGPT-User?
GPTBot collects content that may be used to train OpenAI's models. OAI-SearchBot indexes pages for ChatGPT search, and blocking it removes your site from ChatGPT search answers. ChatGPT-User fetches a page when a user asks ChatGPT to, and OpenAI says robots.txt rules may not apply to it. You can block GPTBot and still allow OAI-SearchBot.
Does blocking Google-Extended hurt my Google Search rankings?
No. Google-Extended is a robots.txt token, not a separate crawler. It controls whether content Googlebot has crawled can be used for Gemini training and grounding, and Google says it doesn't affect inclusion or ranking in Google Search. Blocking Googlebot itself would remove you from Search.
Why does Googlebot show as a "Standard Interactive Browser"?
The inspector only recognizes the 11 signatures listed on this page, and Googlebot isn't one of them. Any string without a known bot signature gets the Standard Interactive Browser label, so treat that label as "not a known bot", not as proof of a human visitor.
Can a scraper fake its User-Agent?
Yes. The User-Agent is an ordinary header, and any client can send any value, including a real crawler's string. Check the connecting IP with reverse DNS (Google, Apple, Common Crawl) or against the operator's published IP list (OpenAI, Anthropic, Perplexity) before trusting it.
Is the User-Agent I paste sent anywhere?
No. Matching runs in JavaScript in your browser tab, and the tool makes no network requests with the strings you paste. The page works offline once it has loaded.
