What This Tool Does, and What It Doesn't

C2PA (the Coalition for Content Provenance and Authenticity) defines Content Credentials: a signed record, called a manifest, embedded in an image or video. It says which tool created or edited the file, what was done to it, and whether AI was involved. Adobe, Microsoft, OpenAI, Google and several camera makers write these manifests.

This inspector is a quick presence check. It reads the file in your browser, computes its SHA-256 hash, and searches the raw bytes for C2PA markers (jumd, c2pa, c2pa.claim, cai:). If it finds them, it pulls out readable labels such as c2pa.created and the IPTC "digital source type" link, and looks for known generator names.

It does not verify the signature, the certificate or the content hash. The "Verified" and "Intact" wording in the results means "C2PA markers found", not "cryptographically valid". To check that a manifest is genuine and the pixels haven't changed, use a full validator such as the Content Authenticity Initiative's c2patool, its open-source SDKs, or the online Verify tool at contentcredentials.org.

How to Use the C2PA Inspector

  1. Choose or drop a file. JPEG, PNG, WebP, AVIF, TIFF and MP4 can be selected. The file is read in your browser and isn't uploaded.
  2. Check the banner. "C2PA Provenance Manifest Located" means markers were found. "No C2PA / CAI Manifest Found" means none were.
  3. Read the extracted strings. Look for c2pa.created and a digitalsourcetype link. trainedAlgorithmicMedia is the IPTC code for AI-generated content.
  4. Export if needed. "Export Manifest JSON" saves the summary, including the full SHA-256 hash, for your notes.

Reading the Digital Source Type

C2PA uses the IPTC digital source type vocabulary to say how content was made. The most common values are:

Value Meaning
digitalCaptureCaptured by a camera or scanner
trainedAlgorithmicMediaCreated by a generative AI model
compositeWithTrainedAlgorithmicMediaReal content combined with AI-generated parts, such as generative fill
algorithmicMediaGenerated by an algorithm that isn't a trained model, such as procedural graphics

The tool's "Digital Source Type" summary is simplified. It reports "Pure AI Generation" if it finds trainedAlgorithmicMedia or algorithmicMedia anywhere in the file, and "Composite / Camera Capture" otherwise, including for edited files. Read the extracted IPTC link for the actual value.

Where Content Credentials Are Stored

The manifest is packed in JUMBF boxes (ISO/IEC 19566-5) and placed in each format's own metadata area:

  • JPEG: APP11 marker segments, split across several segments if the manifest is large.
  • PNG: a dedicated caBX chunk.
  • WebP: a C2PA RIFF chunk.
  • MP4, MOV, AVIF and HEIF: a uuid box in the ISO base media file structure.

Because the manifest lives in metadata, it's easy to lose. Screenshots, many social media uploads, messaging apps and image optimizers re-encode files and drop it. A missing manifest therefore tells you very little: most real photos and many AI images online have none. Some services keep provenance in other ways, such as invisible watermarks or cloud-hosted manifests, which this tool can't read.

What a Valid Manifest Does and Doesn't Prove

  • It proves the manifest was signed by the holder of a certificate and, if the hash checks pass, that the content hasn't changed since signing.
  • It doesn't prove the content is true. A signed photo can still be staged, and the signer's identity is only as trustworthy as the certificate authority behind it.
  • Trust lists matter. The test images above are flagged "untrusted" by the SDK because they use a test certificate. Real validators check the signer against the C2PA trust list.

Frequently Asked Questions

Does this tool verify the C2PA signature?
No. It detects C2PA markers and extracts readable labels, but it doesn't check the signature, certificate or content hash. In our test, files with a broken signature and with edited pixels were both shown as "Verified". Use c2patool, the C2PA SDKs or contentcredentials.org/verify for validation.
If no manifest is found, was the image made by a human?
Not necessarily. Most images online have no Content Credentials, either because the camera or app never added them or because a platform removed them when re-encoding. A missing manifest is neutral evidence.
What does trainedAlgorithmicMedia mean?
It's the IPTC digital source type for content created by a generative AI model. Real images that contain AI-generated parts use compositeWithTrainedAlgorithmicMedia instead, and camera captures use digitalCapture.
Why does re-saving an image remove its Content Credentials?
The manifest is stored in metadata (APP11 segments in JPEG, a caBX chunk in PNG). Editors that don't support C2PA, screenshots and many upload pipelines write a new file without that metadata. Even when it survives, any change to the pixels makes the content hash fail.
Is my file uploaded?
No. The file is read with the browser's File API, the SHA-256 is computed with Web Crypto, and the tool makes no network requests with your file.
