How Zero-Width Prompt Smuggling Works

Large Language Models (LLMs) rely on subword tokenizers (such as Byte-Pair Encoding or WordPiece). Attackers insert non-rendering Unicode codepoints between characters (e.g., I\u200Bn\u200Bstruction) to alter how words are parsed into token IDs:

  • Guardrail Filter Evasion: Simple string matching or WAF regex filters fail to match the prohibited keywords because the string contains intermediate bytes.
  • Tokenizer Ingestion: Many LLM tokenizers strip or map zero-width characters into separate unassigned tokens, allowing the core semantic meaning of the prompt to execute unimpeded.
  • Unicode Steganography: By mapping zero-width spaces (\u200B) to binary 0 and zero-width non-joiners (\u200C) to binary 1, covert instructional payloads can be smuggled inside seemingly benign sentences.
