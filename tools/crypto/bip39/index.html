How BIP39 Mnemonic Generation Operates

The Bitcoin Improvement Proposal 39 (BIP39) specifies a deterministic method for translating raw entropy into human-readable word sequences:

  • Entropy Generation: A cryptographically secure random sequence of length $ENT$ (between 128 and 256 bits) is produced using crypto.getRandomValues.
  • Checksum Appending: A checksum of length $CS = ENT / 32$ bits is created from the first $CS$ bits of the SHA-256 digest of the entropy.
  • Index Mapping: The combined binary sequence is partitioned into chunks of 11 bits. Each 11-bit chunk represents a number between 0 and 2047, which references a specific word in the 2,048-entry wordlist.

Master Seed Derivation (PBKDF2)

To convert the mnemonic words into a 512-bit binary master seed for hierarchical deterministic (HD) wallet paths (BIP32/BIP44), BIP39 utilizes PBKDF2-HMAC-SHA512 with 2,048 rounds. The normalized mnemonic serves as the password, and the UTF-8 string "mnemonic" + passphrase serves as the salt.
