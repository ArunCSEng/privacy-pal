How OpenPGP Operates

OpenPGP (defined under RFC 4880 and updated in RFC 9580) standardizes public-key cryptography for email, text messages, and file verification. It operates via hybrid encryption:

  • Hybrid Encryption Pipeline: A random, ephemeral session key is generated to symmetrically encrypt the message payload using a high-performance symmetric cipher (such as AES-256). The session key is then encrypted with the recipient's public key (using RSA or Curve25519) and bundled into the armored package.
  • Digital Signatures: Authors can authenticate messages by hashing the plaintext (using SHA-256 or SHA-512) and encrypting the digest using their private key (Ed25519 or RSA-PSS), allowing recipients to prove authenticity and non-repudiation.
  • Radix-64 Armoring: Encrypted binary packets are serialized into printable ASCII armor blocks wrapped in standard -----BEGIN PGP MESSAGE----- boundaries containing CRC-24 checksums for transit verification.
