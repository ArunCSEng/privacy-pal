How ChaCha20-Poly1305 Operates (RFC 8439)

ChaCha20 is a stream cipher developed by Daniel J. Bernstein that operates on 64-byte blocks organized in a 4x4 matrix of 32-bit words. Paired with the Poly1305 authenticator, it provides authenticated encryption with associated data (AEAD):

  • Quarter-Round Function: The internal state undergoes 20 rounds (10 column rounds and 10 diagonal rounds) using addition, bitwise XOR, and cyclic bit rotations: $$a \leftarrow a + b, \quad d \leftarrow (d \oplus a) \lll 16, \quad c \leftarrow c + d, \quad b \leftarrow (b \oplus c) \lll 12$$
  • One-Time Authenticator Key: When counter = 0, the first 32 bytes of the ChaCha20 keystream serve as the Poly1305 key $(r, s)$ for that specific packet.
  • AEAD Tag Construction: Poly1305 evaluates a polynomial modulo the prime $2^{130} - 5$ over the padded Associated Data, padded Ciphertext, and lengths to output an unforgeable 16-byte authentication tag.

Constant-Time Software Security

Unlike AES implementations that rely on S-Boxes and lookup tables vulnerable to cache-timing side channels on hardware without AES-NI, ChaCha20 relies exclusively on basic ARX operations (Addition, Rotation, XOR). These execute in fixed clock cycles, rendering the cipher highly resistant to microarchitectural timing attacks.
