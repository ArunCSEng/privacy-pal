How Diceware Passphrase Generation Works

Standard passwords composed of arbitrary symbols are difficult for humans to remember, leading to predictable patterns. Arnold Reinhold designed Diceware to solve this by creating passphrases composed of sequences of real words selected through dice rolls:

  • Physical Analogy: A 6-sided die is rolled 5 consecutive times to form a 5-digit index from 11111 to 66666 (7,776 distinct combinations).
  • Wordlist Mapping: The 5-digit number indexes directly into an official wordlist. Each word provides approximately 12.92 bits of cryptographic entropy.
  • Hardware Entropy Simulation: Rather than physical dice, this tool utilizes the browser's native crypto.getRandomValues() API with unbiased rejection sampling to guarantee uniform distribution across digits 1 through 6.

Entropy Math & Strength Analysis

Passphrase resistance to offline brute-force attacks scales linearly with word count:

  • 4 Words: ~51.7 bits — basic defense threshold for lower-risk accounts.
  • 6 Words: ~77.5 bits — strong defense threshold recommended for master passwords.
  • 8 Words: ~103.4 bits — high security against nation-state supercomputing clusters and specialized ASICs.

Zero Network Egress Security Guarantee

Generating passphrases or passwords on a remote web server creates significant security exposure. BitDark executes the entire Diceware selection pipeline locally inside your browser runtime. The dictionary is compiled into local memory, and no generated passphrases or rolls are ever transmitted across external networks.
