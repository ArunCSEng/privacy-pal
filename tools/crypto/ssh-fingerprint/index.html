How SSH Public Key Fingerprints Are Formatted

An OpenSSH public key file contains three space-separated elements: the key type declaration (e.g., ssh-rsa or ssh-ed25519), a Base64-encoded binary string containing algorithm parameters and public exponents, and an optional trailing comment.

  • Binary Decoding: The fingerprint is generated strictly across the decoded binary blob of the second field, never including the type string or the comment.
  • OpenSSH Modern Standard (SHA-256): The raw binary is hashed using SHA-256, encoded into standard Base64, stripped of trailing padding characters (=), and prefixed with SHA256:.
  • Legacy Format (MD5): The raw binary is hashed using MD5 and rendered as sixteen lowercase two-digit hexadecimal octets joined by colons (e.g., md5:12:34:56:...).
