Architecture & Privacy CORE

What is BitDark.net and how does it fundamentally work?

BitDark.net is an open-access, browser-native cybersecurity, privacy auditing, and developer utility ecosystem. Unlike conventional online converters and security portals that upload your input data to remote servers for processing, BitDark operates under an uncompromising zero-telemetry, client-side execution model.

All file parsing, regex scrubbing, cryptographic operations, and token verification routines execute inside your local device's browser memory (RAM). When you use BitDark, your sensitive source text, files, credentials, and API tokens never travel across the internet to our servers.

How can I verify that my data never leaves my browser?

You can inspect our zero-egress guarantee using standard developer and network auditing tools:

  • Browser DevTools (F12): Open the Network tab in Chrome, Firefox, Safari, or Edge. Upload a file or paste sensitive text into any BitDark tool (such as our EXIF Stripper or PII Redactor) and click process. You will notice 0 outbound XHR, Fetch, or WebSocket requests containing your data.
  • Offline Execution Test: Load any tool page on BitDark.net, turn on Airplane Mode or disconnect your physical internet cable, and continue processing files or encrypting data. The utilities will continue functioning seamlessly because the entire computational engine resides inside your browser.
Which browser technologies enable 100% offline client-side tools?

BitDark leverages modern W3C open web standards to eliminate server dependencies:

  • W3C Web Cryptography API (crypto.subtle): Powers high-speed cryptographic functions such as AES-256-GCM encryption, RSA key generation, and SHA-256/SHA-512 hashing directly through browser hardware acceleration.
  • WebAssembly (WASM): Enables compiled high-performance binaries (such as SQLite engines, Argon2 key derivation, and tokenizers) to run safely in isolated browser sandboxes.
  • HTML5 Canvas & TypedArrays: Facilitates pixel-level metadata manipulation, EXIF GPS purging, and binary magic-byte inspection without remote file parsing.
  • Dedicated Web Workers: Offloads heavy data computations to background browser threads so your interface remains fluid without freezing.
Why does BitDark use Cloudflare Web Analytics?

To monitor platform uptime and optimize delivery performance without tracking our users, BitDark uses Cloudflare Web Analytics. Unlike invasive commercial trackers, Cloudflare Web Analytics is entirely cookieless, does not collect personal identifiers or IP profiles, and does not monitor user journeys across the web. It provides high-level aggregate health metrics such as page requests and HTTP status codes (e.g., 404 monitoring) to ensure reliable site performance.

Advertising & Google AdSense TRANSPARENCY

Does running Google AdSense on BitDark compromise my sensitive data?

No. Google AdSense scripts cannot access your tool data.

Google AdSense runs in strictly isolated document context containers to display banners in designated page margins. The script sandboxing enforced by web browsers ensures that third-party ad scripts have zero access to the private JavaScript variables, typed array memory buffers, cryptographic keys, sanitized text, or uploaded files handled inside BitDark tools.

Why does BitDark display advertisements?

Maintaining and continuously developing over 100 client-side cybersecurity utilities, hosting high-bandwidth edge assets, and writing independent defensive security documentation requires server and operational infrastructure.

Digital advertising through Google AdSense allows BitDark to remain 100% free for everyone worldwide, without implementing subscription paywalls, requiring user registration, or selling data.

How can I control or opt out of personalized ad cookies?

In compliance with Google Publisher Policies and privacy regulations (such as GDPR and CCPA), users have full autonomy over advertising cookies:

  • You can manage your personalized advertising settings directly via Google Ads Settings.
  • You can opt out of third-party advertising cookies via the Digital Advertising Alliance at aboutads.info/choices.
  • You may also configure your web browser to block third-party tracking cookies or utilize standard content-blocking extensions.

What is C2PA manifest inspection and why is it important?

The Coalition for Content Provenance and Authenticity (C2PA) standard allows generative AI platforms and cameras to cryptographically sign digital media. Our C2PA Provenance Manifest Reader inspects JUMBF binary boxes inside JPEG, PNG, and AVIF images locally to reveal the generator model (e.g., DALL-E, Adobe Firefly, Midjourney) and digital source assertions without uploading your images to external cloud APIs.

Does the PII & Prompt Redactor keep a copy of my sanitized text?

No. The AI Prompt & PII Redactor runs strictly via in-memory JavaScript regular expressions in your browser tab. When you sanitize API keys, email addresses, credit cards, or IPv4 addresses before sending your prompt to ChatGPT or Claude, not a single character is recorded or transmitted to any server.
